# UCP-PSE four-scale datasets

The matrices are distributed as compressed assets in the GitHub Release
`datasets-v1`. Run `tools/download_datasets.sh` from the repository root to
download, verify, and extract all four files into this directory.

The small `.meta` files and both checksum manifests are version-controlled.
See `docs/DATASETS_GUIDE.md` for generation, format, validation, compilation,
solver use, and troubleshooting instructions.
